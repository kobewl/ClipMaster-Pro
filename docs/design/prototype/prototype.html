ClipMaster Pro · UI 现代化原型

窗口 800 × 600（与 tauri.conf.json 当前尺寸一致）。所有界面状态按真实尺寸 1:1 绘制， 可直接作为设计交付与 Figma 对照稿。

改动说明

这一版相对现有界面的主要改动

  1. 去掉「窗口中飘一张卡片」：现有实现给应用外层套了 10px 内边距 + 20px 圆角 + 投影 + 径向渐变，看起来像网页嵌在壳里，还白白吃掉一圈可用面积。新版内容面直接铺满窗口，背景改为纯色。
  2. 字号从 5 档收敛到 4 档：原来有 8 / 9 / 10 / 10.5 / 11 / 12.5 / 13 / 15px 混用，最小只有 8px（「PRO」角标）。新版统一为 11.5 / 12 / 13 / 14.5，最小 10.5px 只留给快捷键符号。
  3. 「管理分组」按钮移出滚动区：现有实现把「＋ 管理」放在横向滚动容器里，分组一多就被滚出视野。新版固定在右侧，永远可见。
  4. 分组筛选条去掉「视图」标签：这个标签占了 24px 宽却零信息量，「全部」本身就是最好的说明。
  5. 图片行不再重复提示语：原来每条图片记录都写一遍「图片 / 点击即可粘贴原图」，十条图片就是十遍废话。新版只保留缩略图，信息由左侧图标承担。
  6. 悬停操作区改成实体工具条：原来是两个各自带投影的圆形按钮，压在文字上会糊。新版是一个带描边的整体工具条，并且给行内容预留了 58px 右侧留白。
  7. 选中态改用「浅底 + 细描边 + 左侧短色条」：替代原来的 3px 内阴影色条 + 斜向渐变。渐变在深色模式下几乎不可见，短色条两种模式都成立。
  8. 状态栏降噪：采集状态用绿点 + 绿色文字（暂停时变灰，不用红色），键盘提示用小号 kbd 键帽，右侧「清空未分组」用危险色但只在悬停时显色。
  9. 搜索框快捷键提示改为分体键帽：⌘ K 两个独立小方块，比原来的「⌘ K」一整块更像 macOS 原生控件。
  10. Logo 重做：剪贴板剪影 + 两条内容线（一深一浅），16px 下只保留剪影。详见页面底部。
