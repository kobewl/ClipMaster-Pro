ClipMaster Pro · 新功能原型

两个功能：查看全部内容（长文本 / 图片能看全）和 多选合并复制（勾几条，一起进剪贴板）。 沿用 docs/design/README.md 已定稿的令牌与组件，增量部分见页面底部的说明。

这一版新增了什么、动了什么

  1. 悬停操作区新增「预览」（眼睛图标）：由 2 个按钮变成 3 个，位于分组按钮左边。行正文的右侧留白从 58px 调整到 90px 给工具条让位。
  2. 预览入口有三条路：鼠标走悬停工具条的眼睛按钮；键盘选中某行后按 空格（沿用 macOS 速览的习惯）；双击也行，但双击不是主入口——单击已经是「粘贴」，加双击会让核心操作变慢。
  3. 查看全文弹窗：宽 520px（比设置弹窗的 430px 宽，因为要读长文），正文用 13px / 行高 1.78，比列表里的 1.55 更松。文字可以拖选，底部有「复制」和「粘贴」两个按钮。图片类型用同一个弹窗显示大图。
  4. 多选的最左侧多出一列勾选框：只在多选模式下出现，行内容整体右移 22px。没选中时是空心方框，选中后是实心强调色方块 + 白勾。
  5. 多选模式下，底部状态栏被批量操作条接管（而不是浮在列表上方）：高度从 32px 变 42px，底色换成 accentSoft，左边报「已选几条 · 共多少字」，右边是「取消 / 复制 / 粘贴」。这样不会遮住列表最后几行。
  6. 合并规则写死在文案里：按列表从上到下的顺序，用换行拼接；图片条目会被跳过（图片没法并进文本），如果选中的全是图片则复制按钮置灰。
  7. 状态栏的键盘提示补上「空格 预览」，普通模式下多选入口是状态栏右侧的「多选」按钮，⌘ 点击任意行也能直接进入。
  8. 来源图标改用真实应用图标（prototype/appicons/，16 个，由 NSWorkspace 从本机导出）。原来的 emoji 表在 IntelliJ IDEA 这类工具上会退化成通用图标，用户看不出内容来自哪里。

顺带修掉的一个真实 bug：IDEA 的图标一直取不到

  1. 现象：从 IntelliJ IDEA 复制的内容（比如上面那条 @ApiModelProperty），来源那里显示的是一个 🧠 emoji，而不是 IDEA 的图标。
  2. 根因：来源应用名取的是 System Events 报的进程名（idea，全小写），而 IDE 的显示名是 IntelliJ IDEA。匹配用的是区分大小写的 contains，"IntelliJ IDEA".contains("idea") 为 false，于是取不到图标。
  3. 修法：① 比对时统一转小写；② 同时比对可执行文件名（Contents/MacOS/idea）和应用显示名；③ 加一张进程名 → 目录名的别名表（idea → IntelliJ IDEA、code → Visual Studio Code 等），覆盖应用没在运行时按目录查找的情况。
