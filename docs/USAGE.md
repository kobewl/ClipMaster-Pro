# ClipMaster Pro 使用说明（Beta）

> 安装位置：`/Applications/ClipMaster Pro.app`
> 版本 0.1.0-beta.2 · 2026-09-17

---

## 三个要知道的事

### 1. 唤起窗口的快捷键是 `⌘ \``

**不是**默认的 `⌘⇧V` —— 你之前自己在设置里改成了 **`⌘\``**（Esc 下面那个反引号键），
这个设置存在数据库里，重装不会丢。

想改回去或换成别的：应用里点右上角齿轮 → 「全局快捷键」→ 点击键帽输入新组合。

> 如果快捷键突然不响应了，多半是被别的应用抢占了。改一个组合即可。

### 2. 首次「一键粘贴」需要授权

点历史记录粘贴时，如果没给权限，应用会：
- 自动打开「系统设置 → 隐私与安全性 → 辅助功能」
- 显示提示告诉你打开哪个开关

**打开开关后要重启一次应用**（macOS 只在进程启动时读一次权限）。

> 授权后，粘贴才能把内容自动送进你刚才用的那个应用。
> 没授权也能用 —— 内容会正常进剪贴板，只是要你自己按一下 `⌘V`。

### 3. 数据在这里

```
~/Library/Application Support/pro.clipmaster.desktop/
├── clipmaster.db     历史记录（SQLite）
├── images/           图片剪贴板内容
└── appicons/         来源应用的图标缓存
```

卸载应用**不会**删这些数据。想彻底清空就手动删掉这个目录。

## 日常使用

| 操作 | 方式 |
|---|---|
| 唤起 / 隐藏窗口 | `⌘ \`` |
| 搜索 | 直接打字，或用 `⌘K` 聚焦搜索框 |
| 键盘选择 | `↑` `↓` 移动，`↵` 粘贴 |
| 粘贴到刚才的应用 | 点某条记录，或选中后按 `↵` |
| **查看全部内容** | 悬停记录 → 眼睛图标；或选中后按 `空格` |
| **放大图片** | 图片预览里点图片切 100% / 适应窗口，或用 `−` `+` |
| **多选合并复制** | 底部「多选」→ 点几条勾上 → 「复制」或「粘贴」（`↵` 也行） |
| 只复制不粘贴 | 悬停记录 → 操作区 |
| 分组 | 悬停记录 → 文件夹图标 |
| 删除单条 | 悬停记录 → 垃圾桶图标 |

**三个新功能说明**：

- **查看全部内容**：列表里每条只显示两行，长消息看不全。悬停时点眼睛图标
  （或选中后按空格）会弹出完整内容，文字可以直接拖选。
- **放大图片**：图片在预览弹窗里可以放大看细节。**点一下图片**切到 100%，
  再点一下回到「适应窗口」；旁边还有 `−` `+` 按钮和当前百分比
  （点百分比也能回到适应窗口）。用的是 `⌘` + 滚轮可以连续缩放。
  放大后直接拖动图片平移，右下角会显示原图尺寸。
- **多选合并复制**：点底部「多选」进入多选模式，点几条勾上，再点「复制」或「粘贴」。
  合并规则是**按列表从上到下的顺序、用换行拼接**，图片条目会被跳过。
  多选模式下 `⌘A` 全选、`Shift` 点击可以连选一段、`Esc` 退出。
  合并出来的内容不会进入历史记录。

> 多选模式下**点整行就是勾选**（不是粘贴），因为勾选要连续点好几条，
> 而粘贴走底部按钮或 `↵` 一样快。

**默认设置**（可在设置里改）：

- 最大历史数量：1000 条
- 保留天数：30 天（0 = 不按天清理）
- 剪贴板采集：开启
- 开机自启：关闭（设置面板最下面「系统」里打开）

### 开机自启

在设置面板的「系统」一节里打开。打开后：

- 开机时应用会自动在后台启动，**不会弹窗口**，按 `⌘ \`` 随时唤起。
- 开的是 macOS 标准的登录项（`~/Library/LaunchAgents/pro.clipmaster.desktop.plist`），
  也可以用「系统设置 → 通用 → 登录项」查看和关闭。
- **开发版（`npm run tauri dev`）不能开这个开关** —— 它要靠 Vite 开发服务器才能显示
  界面，注册成登录项后开机只会弹一个空白窗口。装好正式版本再开。

## 已知问题

### 界面是「旧版 UI + 两个新功能」

整体视觉还没有换成 `docs/design/` 里定稿的新版（差异见 `docs/design/README.md` 第十节），
但**查看全部内容**、**图片放大**、**多选合并复制**这三个新功能已经装上了，
交互与设计稿一致（截图见 `docs/design/prototype/shots/14` ~ `18`）。

### 更新到新版本后，粘贴可能要重新授权

应用没有代码签名证书，用的是 ad-hoc 签名，而 macOS 的「辅助功能」权限是按
**二进制的指纹**（CDHash）记的 —— 每次重新编译，指纹都会变，于是之前授过的权
就失效了。

**但系统设置里的开关看起来还是开着的**（那是旧指纹的记录），这是最容易误判的地方。

更新完如果一键粘贴没反应，去「系统设置 → 隐私与安全性 → 辅助功能」把
ClipMaster Pro **先关掉再打开**，然后重启应用。

### 图标已修复，但 Dock 可能需要刷新

Logo 的留白问题（Dock 里显得比邻居大一圈）已经修好并重新生成了全部图标。
如果 Dock 里还是旧图标，执行一次：

```bash
killall Dock
```

### 这是 Beta

- 没有代码签名证书，首次打开可能需要在「系统设置 → 隐私与安全性」里点「仍要打开」
- 没有自动更新，重新安装就是覆盖 `/Applications/ClipMaster Pro.app`

## 出问题了怎么办

**粘贴没反应** → 检查「辅助功能」权限（见上文第 2 点），授权后重启应用。

**窗口不见了** → 按 `⌘ \``；如果没反应，看看是不是被别的应用占了快捷键。

**历史记录不更新** → 底部状态栏看「正在采集」还是「已暂停」；暂停了就在设置里打开采集。

**应用起不来** → 从终端启动能看到日志：

```bash
"/Applications/ClipMaster Pro.app/Contents/MacOS/clipmaster-pro"
```

排查记录在 `docs/troubleshooting/`。
